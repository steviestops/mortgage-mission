Mortgage Mission V3
===================

Files in this folder form an installable Progressive Web App (PWA).

To use it as an iPhone web app:
1. Upload the whole folder to an HTTPS web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the resulting URL in Safari on iPhone.
3. Share > Add to Home Screen > Open as Web App.

The app stores its data in the browser on the device. It does not connect to Santander.
